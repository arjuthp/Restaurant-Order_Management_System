## 📝 INSTRUCTIONS FOR DOWNLOADING IMAGES:

### Step 1: Search for Images
For each product, search on:
- Google Images: `https://www.google.com/search?q=[product name]&tbm=isch`
- Unsplash: `https://unsplash.com/s/photos/[product name]`
- Pexels: `https://www.pexels.com/search/[product name]`

### Step 2: Download & Rename
- Download high-quality images (at least 800x600px)
- Save as: `product-name.jpg` (lowercase, hyphens instead of spaces)
- Examples:
  - "Dal Bhat Set" → `dal-bhat-set.jpg`
  - "Chicken Momo" → `chicken-momo.jpg`
  - "BBQ Chicken Pizza" → `bbq-chicken-pizza.jpg`

### Step 3: Save Location
Save all images to: `src/uploads/products/`

### Step 4: File Naming Convention
```
Product Name          →  Filename
─────────────────────────────────────────
Dal Bhat Set          →  dal-bhat-set.jpg
Chicken Momo          →  chicken-momo.jpg
Margherita Pizza      →  margherita-pizza.jpg
French Fries          →  french-fries.jpg
Chocolate Lava Cake   →  chocolate-lava-cake.jpg
```
